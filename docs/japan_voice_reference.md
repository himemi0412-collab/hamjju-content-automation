# 일본 쇼츠 음성 참고 기준

## 운영 원칙

- 한 영상에는 한 명의 화자만 사용한다.
- 이야기의 주인공과 시점에 맞춰 20대 여성·60~70대 여성·20대 남성·60~70대 남성 중 하나를 선택한다.
- 모든 음성은 `fal-ai/gemini-3.1-flash-tts`, 일본어, temperature 1.1을 사용한다.
- 기계식 TTS·방송·광고·애니메이션 연기를 금지하고 자연스러운 호흡, 망설임, 문장 끝이 살짝 내려가는 사람다운 감정을 우선한다.
- 재생 가능한 참고 음성을 사용자가 직접 듣고 승인하기 전에는 후보를 제작 기본값으로 승격하지 않는다.

## 현재 참고표

| 프로필 | Fal voice | 상태 | 용도 |
|---|---|---|---|
| 60~70대 여성 | Gacrux | 승인됨 | 따뜻한 회상, 그리움, 약간의 슬픔과 체념 |
| 20대 여성 | 미정 | 참고 음성 필요 | 젊은 시점의 일기·첫사랑·일상 회상 |
| 20대 남성 | Puck 후보 | 생성 재시도 승인 대기 | 가까운 사람에게 조용히 말하는 젊은 남성 |
| 60~70대 남성 | Algenib 후보 | 생성 승인 대기 | 낮고 따뜻하며 세월감 있는 회상 |
