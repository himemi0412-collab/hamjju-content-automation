# 햄찌 iPhone 단축어 팩

이 폴더는 콘텐츠 자동화와 분리된 iPhone Shortcuts 전용 소스입니다.

- thought_capture.cherri → 🧠 생각났어!
- calendar_entry.cherri → 📅 일정 넣기
- today_one.cherri → 🎯 오늘 딱 하나
- focus_25.cherri → 🔥 25분 집중
- battery_manage.cherri → 🔋 배터리 관리

의도된 iPhone 연결:
- 뒷면 이중 탭 → 🧠 생각났어!
- 뒷면 삼중 탭 → 📅 일정 넣기
- 배터리 30% 이하 → 🔋 배터리 관리
- 배터리 80% 이상 → 🔋 배터리 관리
- 필요할 때 홈 화면/위젯 → 🎯 오늘 딱 하나, 🔥 25분 집중

이 브랜치는 main/production 자동화와 병합하지 않습니다.
