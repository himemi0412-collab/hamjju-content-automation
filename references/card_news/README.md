# 블로그 카드뉴스 레퍼런스 정본

이 폴더는 햄찌 블로그 카드뉴스의 영구 레퍼런스와 제작 기준을 보관한다.

## 정본 파일
- `cover_explorer/`: 사용자 제공 5장 + ZIP 33장, 총 38개 원본
- `production_prompt_ko.md`: 사람이 편집한 듯한 결과를 위한 실제 생성 프롬프트
- `production_style_contract.json`: 자동화가 읽는 기계 판독 계약
- `prompts/qa_photographic_blog_cards.md`: 최종 PNG 독립 QA

## 38개 레퍼런스에서 확인한 공통 특징
- 한 카드 한 메시지, 짧고 강한 제목, 명확한 제목/본문/번호 위계
- 노트·메모지·브라우저 창·카드·체크리스트·테이프·클립·밑줄 같은 친숙한 편집 장치
- 실제 사물 또는 단순 선화가 주인공이며 장식은 보조
- 넓은 여백, 분명한 정렬축, 약한 비대칭과 부분 겹침
- 한 세트 안에서 색군은 통일하고 카드별 공간 분할과 시선 흐름은 변화
- 정보량을 제한하고 모바일에서 한눈에 읽히는 굵은 한글 사용
- 사진형, 손그림형, 노트형 등 스타일은 다양하지만 한 카드 안에서는 표현 방식이 일관됨

## 제작 원칙
1. 주제별 생활 사물·행동이 담긴 무문자 장면 생성
2. 가짜 글자·로고·해부학·사물 구조 오류 검사
3. 정확한 한글을 로컬 타이포 레이어로 별도 합성
4. 5장 역할·구도·가독성·AI 티 QA
5. 통과 결과만 Notion 및 네이버 임시저장 경로로 전달

## 고정 5장 역할
1. cover: 핵심 질문/답과 대표 사물
2. flow: 원인 또는 행동 흐름
3. comparison: 같은 척도·시점의 A/B 비교
4. checklist: 3~5개 항목과 실제 점검 행동
5. decision: 최종 판단과 다음 행동 하나

## 시각 기준
- 1254×1254, 안전 여백 8~10%
- 생활 장면 58~72%, 한글 28~38%
- 화이트·쿨화이트·쿨그레이 + 라벤더·민트·파우더블루·코랄 등 3~5색
- 카드당 핵심 문장 1~2개, 수동 줄바꿈, 모바일 우선
- 세트 일관성은 유지하되 5장 모두 공간 분할·크롭·제목 위치를 기계적으로 반복하지 않음
- AI 생성 느낌 허용치 5/100 미만

## 금지
- 노랑·머스터드·금빛·누런 크림·베이지 지배·세피아
- 이미지 생성 단계의 모든 글자·로고·워터마크
- Codex·ChatGPT·터미널·코드·앱 UI·AI 로고
- 의미 없는 아이콘·큐브·그라데이션·유리질·네온·3D 광택
- 손가락/사물/빛/접촉 오류와 기계적 반복 패턴
- 모든 카드의 동일 틀·동일 크롭·동일 장식
- 특정 레퍼런스 문구·로고·캐릭터·레이아웃 복제
- 네이버 공개·예약 발행
