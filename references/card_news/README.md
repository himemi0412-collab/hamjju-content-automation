# 블로그 카드뉴스 레퍼런스 정본

이 폴더는 햄찌 블로그 카드뉴스의 영구 레퍼런스와 제작 기준을 보관한다.

## 원본 자산

- `cover_explorer/`: 사용자가 제공한 표지 디자인 탐색 자료 5장과 원본 ZIP
- 표지 탐색 자료에는 20개의 편집 디자인 언어가 포함된다.
- 이 자료는 **레이아웃·타이포 위계·여백·정보 구조 탐색용**이다.
- 특정 카드의 문구, 로고, 캐릭터, 앱 화면, 장식은 복제하지 않는다.

## 탐색기와 실제 제작의 분리

### 표지 디자인 탐색기

20개 스타일을 비교·선택하기 위한 별도 도구다. 기술 UI, 터미널, Codex, ChatGPT, 스크린샷 표현이 포함될 수 있다.

### 실제 블로그 카드뉴스 생성기

생활 정보 주제의 실제 사물과 행동을 먼저 보여준다. 탐색기의 기술 소재나 앱 UI를 실제 카드에 가져오지 않는다.

1. 주제별 생활 사물·행동이 담긴 **무문자 장면** 생성
2. 가짜 글자와 로고가 없는지 확인
3. 정확한 한글을 로컬 타이포 레이어로 별도 합성
4. 5장 역할·구도·가독성 QA
5. 통과한 결과만 Notion 및 네이버 임시저장 경로로 전달

## 고정 5장 역할

1. `cover`: 문제 상황을 즉시 보여주는 표지
2. `flow`: 실제 원인 또는 행동 흐름
3. `comparison`: 같은 크기·시점의 조건 비교
4. `checklist`: 손이 실제 점검 행동을 수행하는 장면
5. `decision`: 최종 안전 상태 또는 판단

## 시각 기준

- 정사각형 1254×1254 우선
- 생활 장면 65~72%, 한글 영역 28~35%
- 밝은 흰색 또는 쿨톤 배경
- 라벤더·민트·파우더 블루·코랄 중심
- 굵고 정확한 한글, 카드당 핵심 문장 1~2개
- 넉넉한 여백과 모바일 우선 가독성
- 5장 모두 서로 다른 구도와 정보 구조
- 사진·생활 사물·행동이 텍스트보다 먼저 읽혀야 함

## 금지 사항

- 노랑, 머스터드, 금빛, 누런 크림, 베이지 지배, 세피아
- 생성 이미지 내부의 한글·영문·숫자·가짜 문자
- Codex, ChatGPT, 터미널, 코드, 앱 UI, AI 로고
- 떠다니는 아이콘, 추상 기술 큐브, 의미 없는 인포그래픽 노드
- 동일 장면·동일 크롭·동일 템플릿의 5장 반복
- 글자가 장면을 압도하는 구성
- 네이버 공개 또는 예약 발행

## 만족 결과 기준

2026-09-22 일회성 테스트에서 사용자가 만족한 방향:

- 노트북·RAM·통풍 행동을 실제 생활 사진으로 표현
- 이미지에는 글자를 생성하지 않고 한글을 나중에 합성
- 표지·원인·비교·점검·판단의 구도 차별화
- 화이트·라벤더·민트·블루·코랄 조합
- 둥근 흰색 타이포 패널과 굵은 한글
- 기술 UI와 노란색 계열 없음

기계 판독용 계약은 `production_style_contract.json`을 정본으로 사용한다.
