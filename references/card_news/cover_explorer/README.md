## 사용 범위

이 폴더의 자료는 **표지 디자인 탐색기 전용**이다. 실제 블로그 카드뉴스 생성에서는 아래 요소만 추출해 활용한다.

- 타이포 위계
- 여백과 정렬
- 모듈형 정보 구조
- 카드별 구도 차별화
- 편집 디자인의 밀도와 리듬

아래 요소는 실제 생활 정보 카드로 전송하지 않는다.

- Codex·ChatGPT·터미널·코드·앱 화면
- AI 로고와 기술 아이콘
- 특정 원본 문구·장식·구도의 그대로 복제
- 노란색·머스터드·금빛·세피아 중심 스타일

실제 제작의 정본은 상위 폴더의 `README.md`와 `production_style_contract.json`이다.
