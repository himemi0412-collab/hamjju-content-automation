# 햄찌 블로그 카드뉴스 제작 프롬프트 v3

## 목적
사용자 제공 레퍼런스 38개에서 추출한 편집 원리를 적용하되, 특정 문구·로고·캐릭터·구도를 복제하지 않는다. 결과는 “AI가 한 번에 만든 그림”이 아니라 사람이 자료를 고르고 조판한 편집 디자인처럼 보여야 한다. 시각 QA의 AI 생성 느낌 허용치는 5/100 미만이다.

## 입력
- 주제: {{topic}}
- 핵심 답: {{core_answer}}
- 카드별 사실: {{card_facts}}
- 생활 사물·행동: {{real_objects_and_actions}}
- 금지 또는 주의할 단정: {{factual_cautions}}

## 공통 아트디렉션
1. 한 카드에는 메시지 하나만 둔다.
2. 생활 사물 또는 행동을 주인공으로 삼고, 제목·설명·장식은 보조로 둔다.
3. 1254×1254 정사각형. 바깥 안전 여백 8~10%, 생활 장면 58~72%, 조판 영역 28~38%.
4. 제목은 1~2줄, 본문은 필요할 때만 2~4줄. 정확한 한글은 이미지 생성 뒤 코드로 별도 조판한다.
5. 제목/본문/번호의 크기 차이를 분명히 하고, 굵은 고딕 계열을 사용한다. 글자에 불필요한 광택·입체·왜곡을 넣지 않는다.
6. 흰색·쿨화이트·쿨그레이를 바탕으로 라벤더·민트·파우더블루·코랄 등 3~5색만 선택한다. 카드 세트는 같은 색군을 공유하되 카드마다 포인트 배치를 바꾼다.
7. 노트, 메모지, 창, 카드, 체크리스트, 라벨, 테이프, 클립, 밑줄 같은 편집 장치는 주제에 맞는 것 1~2개만 사용한다.
8. 완벽한 좌우대칭을 피하고, 약한 비대칭·의도적 여백·부분 겹침으로 사람이 편집한 리듬을 만든다.
9. 선화/평면 일러스트/깔끔한 제품 사진 중 주제에 가장 자연스러운 한 가지를 주축으로 삼는다. 서로 다른 렌더링 스타일을 한 카드에 섞지 않는다.
10. 카드 5장은 한 세트로 보이되, 동일 틀·동일 크롭·동일 제목 위치를 반복하지 않는다.

## 5장 편집 역할
1. cover: 핵심 질문 또는 답을 1~2줄로 크게 제시하고 실제 핵심 사물 하나를 강하게 보여준다.
2. flow: 원인이나 순서를 2~3단계로 보여주되 실제 장면 안에서 읽히게 한다.
3. comparison: 같은 척도와 시점의 A/B 비교. 차이는 2~3개만 강조한다.
4. checklist: 3~5개 항목과 실제 점검 행동을 결합한다. 체크박스만 떠다니게 하지 않는다.
5. decision: “이 상태면 괜찮음/점검 필요”처럼 독자가 바로 판단할 결론과 다음 행동 하나를 보여준다.

## 인간 편집감 필수 신호
- 정보 위계가 3단계 이상 분명함
- 제목 주변에 충분한 숨 쉴 공간
- 실제 사물의 비례·접촉·손동작이 자연스러움
- 장식은 내용과 관계가 있고 반복 패턴이 기계적이지 않음
- 카드별 서로 다른 공간 분할과 시선 흐름
- 문장 길이에 맞춘 수동 줄바꿈
- 약간의 비대칭과 편집 흔적은 허용하되 정렬 기준은 명확함

## 절대 금지
- 생성 이미지 내부의 한글·영문·숫자·가짜 문자·워터마크·로고
- 노랑·머스터드·금빛·누런 크림·베이지 지배·세피아
- Codex·ChatGPT·터미널·코드·채팅창·앱 UI·AI 로고
- 떠다니는 의미 없는 아이콘, 추상 큐브, 과도한 그라데이션, 유리질, 네온, 3D 광택
- 사람 손가락 오류, 뒤틀린 사물, 불가능한 그림자·반사·접촉
- 스톡 이미지 같은 과잉 미소, 광고용 과포화, 영화적 심도, 과도한 보케
- 모든 요소가 지나치게 매끈하고 균일한 AI 템플릿 느낌
- 카드 5장에 같은 상단 박스·같은 크롭·같은 장식 반복
- 특정 레퍼런스의 문구·상표·캐릭터·레이아웃 복제
- 사실 근거 없는 수치·제품 형태·브랜드 단정
- 네이버 공개·예약 발행

## 생성 순서
A. 먼저 글자·로고가 전혀 없는 생활 장면만 생성한다.
B. 해부학·사물 구조·광원·접촉·중복 패턴을 검사하고 이상이 있으면 해당 카드만 재생성한다.
C. 승인된 장면 위에 정확한 한글을 로컬 조판한다.
D. 카드 간 구도 중복, 모바일 축소 가독성, 색상 금지, AI 티를 독립 검수한다.
E. AI 생성 느낌 점수가 5 이상이면 실패다. 실패 원인만 고쳐 최대 2회 재시도하고 통과 카드에는 손대지 않는다.

## 출력 계약
각 카드에 role, visual_subject, composition, typography, palette, editorial_device, negative_prompt를 제공한다. 최종 PNG 5장과 QA JSON을 남긴다.
